# Team Operating Model

Dokumen inti untuk tim yang bergerak independen dan ingin tetap simpel.

## Aturan Inti
- Ambil satu task kecil, kerjakan langsung.
- Kalau task hanya menyentuh area sendiri, jangan menunggu koordinasi tambahan.
- Kalau task menyentuh area bersama, buat PR singkat dan minta review seperlunya.
- Kalau bingung, tanya langsung ke owner area terkait.

## Peran Ringkas
- Data Scientist: urus data, eksperimen, dan feature schema.
- AI Engineer: urus pipeline, service inference, dan schema bersama.
- Backend Engineer: urus API, auth, dan integrasi.
- Frontend Engineer: urus UI dan konsumsi API.

## Aturan Praktis
- Branch cukup `main` dan `feature/<task>`.
- PR kecil lebih baik daripada PR besar.
- Review fokus ke bug, kejelasan, dan dampak langsung.
- Jika mengubah kontrak data/API, tulis catatan singkat di PR.
- Hindari ritual yang tidak mempercepat delivery.

## Definition of Done
- Kode jalan.
- Ada bukti uji minimal.
- Dokumentasi terkait sudah diperbarui kalau perlu.
